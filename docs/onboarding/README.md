# Onboarding

Seat onboarding documentation will cover native surfaces, the available Fleet
interface, canonical-surface instructions, and the three required identity
proofs: authenticated read, authorized own-seat write, and rejected cross-seat
write.

Credential values never belong here.

The production identity and native-access runbook is
[`cloudflare-access.md`](cloudflare-access.md). It is executable guidance for a
later owner-authorized provisioning pass; its presence does not provision a
resource, distribute a credential, or prove native access.
